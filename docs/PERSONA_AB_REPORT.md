# Отчёт A/B системных промптов Тимура

Проведён 2026-08-19 на реальном продакшн-пайплайне `build_chat_messages` + реальная модель `openai/gpt-5.6-luna` (polza.ai). Сцены: анонимизированный quality-корпус (`tests/fixtures/humor_quality_scenes.json`, 14 ambient-сцен) + 6 direct-сцен из `tests/fixtures/humor_replay.json`. Оценка: слепой LLM-судья (funny/cringe/natural 0-10) + детерминированные метрики длины, шаблонов, кринж-маркеров.

## Варианты

- **A** — baseline: текущий системный промпт до изменений
- **B** — A + «цель по длине — одна короткая фраза, обычно 2-8 слов» + «если добивка длиннее фразы — урезай до сути или молчи»
- **C** — B + анти-кринж: не стараться казаться смешным, не объяснять шутку, не начинать с «ну»/«понимаешь»/«кстати», писать как кинутую реплику между делом
- **D** — C + регистр «живого пацана»: не разговор, а кинутая реплика; одна деталь из сцены без подводок; иногда хватает одного слова; не поучать, не давать советов без запроса; лучший ответ — тот, после которого хочется продолжить болтать

## Что зафиксировано в продакшн

Вариант D включает две новые жесткие инструкции из промпта «живого пацана» (строки 26-27 `config/persona.yaml`):

- **анти-кринж**: не пытаться казаться смешным; если нечего сказать точно — отвечать по делу или молчать;
- **регистр**: не разговор, а кинутая реплика; одна деталь сцены без подводок; иногда хватает одного слова; не поучать.

Полный отчёт с судейскими оценками всех 20 сцен по каждому варианту — в `/tmp/persona_ab_report.json` (локально, в git не коммитится из-за персонализируемых данных).

## Воспроизводимость

```bash
python3 -m timur_bot.tools.persona_ab --variants A,B,C,D     # полный прогон
python3 -m timur_bot.tools.persona_ab --scopes ambient        # только ambient-сцены
python3 -m timur_bot.tools.persona_ab --no-judge              # только объективные метрики
```

Команда не меняет `memory.json`. Слепой судья вызывается после генераций, порядок вариантов в сцене перемешивается (seed=42).
